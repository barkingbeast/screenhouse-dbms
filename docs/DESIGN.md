# Screenhouse design — Midnight Premiere

Rebuilt using the supplied modern-web-ui skill. A refined cinema box office with original film-inspired artwork, a four-show selection strip, a theater-like seat map, and a warm ivory checkout shaped like a physical ticket. Customers, history, and the SQL lab share the same typography and spacing system.

Palette: midnight #101A26, raised navy #162230, ivory #F3ECDF, champagne #DFBC80, slate #B0BAC4, warm ticket paper #F0E7D7. Prata display headings and Outfit body/control text are bundled locally for offline use. Artwork uses CSS planetary forms, orbit lines, desert horizons, and action-inspired geometry, with no remote image dependencies.

Layout: left-aligned editorial hero balanced by a film-art panel; horizontal shows above an asymmetrical auditorium/checkout workspace. No ornamental dashboard metrics. Ticket cutouts and perforations are the distinctive physical motif. Mobile stacks the artwork, seats, and checkout, preserving all review tools. Focus rings, seat labels, selected state, disabled booked state, navigation current state, and reduced-motion support are retained. Booking confirmation remains server-confirmed; no optimistic ticket claims.

Fonts obtained from Google Fonts: Outfit and Prata, with license files bundled under public/fonts. No runtime network dependency for typography.
